# 우리의 교실, 그리고 너

한국어 고등학교 청춘 비주얼 노벨. 1학년부터 3학년 졸업까지, 73개 소챕터와 88개 장면, 캐릭터 5명, 졸업 결말 16개.

## 실행

index.html을 브라우저에서 열면 실행됩니다. 별도 설치, 서버, 빌드가 필요 없습니다. 이미지와 글꼴을 포함합니다.

## GitHub Pages 배포

1. 이 폴더 안의 index.html, style.css, game.js, story.js, 이미지들과 fonts 폴더를 저장소 루트에 올립니다. 폴더 구조를 유지하세요.
2. 저장소 Settings → Pages → Deploy from a branch를 선택합니다.
3. main 브랜치와 /(root)를 고르고 Save를 누릅니다.
4. 배포가 끝나면 표시되는 Pages 주소로 접속합니다.

단일 HTML 버전을 받은 경우에는 파일명을 index.html로 바꿔 저장소 루트에 올리는 것만으로도 배포할 수 있습니다.

## 조작

- Enter / Space: 대화 진행, 출력 중이면 문장 전체 표시
- 숫자 1–9 / 숫자패드: 화면에 보이는 번호의 선택지 선택
- Esc: 열린 메뉴 닫기
- 선택 직후 오른쪽 위에 실제 호감도 변화와 현재 수치가 표시됩니다.
- 소챕터마다 자동저장하며, 페이지를 닫을 때도 현재 진행을 저장합니다. 시작 메뉴의 계속하기로 이어갑니다.
- 완료한 소챕터는 챕터 선택에서 선택 직전으로 돌아갑니다. 당시 호감도와 사건 기록을 복원하고, 그 이후는 새 선택으로 진행합니다. 해금한 챕터와 앨범은 유지됩니다.
- 화면 아래에는 다섯 인물의 관계를 대략적인 바와 표현으로 표시합니다. 정확한 숫자는 바에 표시하지 않습니다.
- 저장과 챕터 해금은 현재 브라우저에 보관됩니다. 로컬 파일과 GitHub Pages는 저장 공간이 서로 다릅니다.

## 파일

- story.js: 장면, 대사, 선택지, 엔딩
- game.js: 진행, 저장, 호감도, 키보드 조작
- style.css: 화면과 글꼴
- fonts/: 오프라인 글꼴 (SIL Open Font License; 함께 제공한 OFL 문서 참고)

초반 호감도로 개인 루트가 고정되지 않습니다. 졸업 직전까지 다섯 인물의 이야기를 함께 겪습니다. 졸업식에서 전할 마음을 고르고, 세 해 동안의 관계와 선택으로 결말이 달라집니다.

story.js의 SCHOOL_YEARS / CHAPTERS는 시간표와 소챕터를 정의합니다. 새 장면은 Q의 affection 속성, 기존 장면은 game.js의 COMMON_AFFECTION / PERSONAL_AFFECTION에서 호감도를 수정할 수 있습니다.

저장 키는 class-long-auto-v4(이어하기), class-long-chapters-v4(완료 챕터의 선택 직전 상태), class-long-album-v4(졸업 앨범)입니다. 이전 단편 버전의 데이터는 지우지 않지만 장편에서는 새 게임으로 시작합니다.

가영은 관심을 받고 싶어 먼저 투정 부리는 댄스부원, 예빈은 담요를 덮고 쉬다가 깨면 조잘조잘 이야기하고 잘 웃는 성격으로 변경했습니다.
